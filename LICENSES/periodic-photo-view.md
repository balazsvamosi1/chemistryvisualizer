# Periodic photo mode: image credits and licensing

The optional photo view uses an image-URL metadata index adapted from
[Bowserinator/Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON),
whose repository is licensed under
[Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
Changes: only atomic number, image title, URL, attribution, and a conservative
"illustration" marker are retained. The index is not evidence of photo authenticity.

**Each third-party image has its own rights**. The individual credit is displayed
in the element's expanded photo panel. Where the source explicitly marks an
illustration, the tile says so. A missing-image placeholder is shown for elements
without a sample. Displaying a third-party image is not a claim that the project
owns that image or that it is an authentic photograph of the element.

The app does not package or redistribute image binaries. In photo mode, image
URLs are loaded directly from Wikimedia Commons or images-of-elements.com.
The browser must have network connectivity. Upstream availability and image
licenses may change; verify them before redistributing downloaded image files.

Source JSON attribution: Bowserinator, *Periodic-Table-JSON*, CC BY-SA 3.0.
License information for the metadata index is separate from the Chemistry Lab
source code license.
